# WinToPod 品牌素材

使用项目提供的黑色、白色透明睡猫 PNG，保留各自图像像素，移除不必要的 PNG 元数据。`tools/BuildBrand.py` 只按不透明轮廓裁剪外围透明边距、居中缩放并封装多尺寸 ICO，不重画图案，不添加底板、矩形、描边或装饰。

黑色用于浅色背景，白色用于深色背景。窗口及关于遵循应用主题，托盘遵循系统任务栏主题；可选浏览器助手在收到系统主题状态后切换其按钮图标。EXE 资源提供黑色静态图标；Shell 缓存及固定快捷方式不由程序强行刷新。

输出包含 16、20、24、32、40、48、64、128、256 像素的透明 PNG 与 ICO。原始 PNG 不嵌入 EXE；运行时只使用缩放资源。无需再由截图提取轮廓或运行外部矢量化工具。

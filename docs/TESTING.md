# V1.0 验证范围

本次公开整理版本执行以下检查。统计对应保留的生产实现，已移除仅覆盖废弃连接原型的旧测试，不把删除后的测试计入通过数。

| 检查 | 结果 | 能说明什么 |
| --- | --- | --- |
| 基础检查 | 78 项通过 | 协议基础、发现、加密帧、PTP、PCM、连接内测试音与诊断过滤。 |
| 自动连接策略 | 28 项通过 | 现行保守/激进决策、本机输入门控、暂停与退避的纯策略行为。 |
| 独立接收端模拟 | 21 种通过 | 单只控制、时间就绪、音量与静音回读。 |
| 原生立体声对模拟 | 39 种通过 | 双成员鉴权、帧/时间轴、失败停止、密码、回退和静音/恢复。 |
| 播放验证模拟 | 15 种通过 | 接收端隔离、Digest、凭据复用及错误处理。 |
| 稳定性模拟 | 8 种通过 | 事件确认、中断及约 11 分钟连续双成员发送；两路各 82,976 包。 |
| 生产采集边界 | 4 项通过 | 应用混音、包含本程序启动的播放器与安全混合；设备边界替代。 |
| Windows 音量边界 | 6 项通过 | 静音保留档位、取消静音、通知去重及释放后停止操作；设备边界替代。 |
| PCM 保真 | 4 项通过 | 全部 16bit 取值、声道顺序、低位样本及静音保真。 |
| 原生接口布局 | 7 项通过 | 激活参数布局、COM 可见性与接口标识；没有执行 Windows 原生激活。 |
| 视频状态接口 | 20 项通过 | 本机接口协议、输入边界与延迟参数。 |
| 浏览器生命周期 | 10 项通过 | 有界缓冲、暂停/拖动、释放与状态恢复；编解码边界替代。 |
| 发布资源 | 通过 | 透明黑白图标、九档尺寸、程序集资源与 Windows EXE 版本核对。 |
| 公开文件检查 | 通过 | 目录入口、构建/用户数据排除、敏感标记及文档链接。 |

Windows 自包含 EXE 在 Linux 交叉编译。Windows 界面/DPI、实际应用混音采集、DPAPI、任务栏切色、真实响度和这次构建的 HomePod 声学效果，**没有在当前环境执行**。Windows 专用自检已随本次源码编译，GitHub Windows CI 已配置，尚未实际运行。

当前环境没有可执行的 Chromium，未重新执行真实浏览器/VP8 检查，也没有验证 B 站实站或完整 MV3 安装。保留可运行的检查脚本，不用替代环境的通过冒充真实浏览器验证。

开发期间已有真实 HomePod mini 原生对双只发声反馈；这提供了协议方向的实机证据，不能保证所有型号/固件、后续变更或长时间播放均无问题。多只独立音箱同步和系统级全局音画补偿尚未实现。

便携包 `docs/VALIDATION.json` 记录该次打包实际找到的报告和 EXE 哈希。后续自行构建时，缺少的可选回归在报告中为 null；不要沿用本表声称未执行的测试已通过。

# V1.2 播放稳定性体验

这是开发体验包，未经本轮HomePod真机验收；程序内版本暂保留V1.1，不是正式V1.2。27.2灯效和新HomePod真机适配尚未完成。

先从托盘退出旧程序，完整解压到独立目录。双击 `Start-V1.2-Preview.cmd` 启用时钟对齐发送、采集率补偿、有限卡顿恢复及媒体信息同步；日志应出现“已启用V1.2时钟对齐与采集率补偿试验”。双击普通 `WinToPod.exe` 使用原策略作对照；切换前须退出托盘。登录启动仍使用原策略，体验开关不保存。

两种入口共享现有配对、音量和设置；原有自动连接偏好仍生效。采集断供后需要重新积累约100ms输入。PTP失效、失去控制权等保护保持原样。合成波形不等于听感验收。

建议低音量开始，依次验证：单只/立体声双只可听与左右声道；相同音源的低音量、人声、高频音质；暂停30秒再恢复重复5次；静音恢复；iPhone接管后的退让；连续播放1–2小时（有条件到8小时）；兼容播放器声音。记录爆音、变调、起音缺失或断联时刻。

每30秒及停止时的“采集率补偿”行包含补偿ppm、缓冲、丢弃、补零、重新预缓冲和限幅计数。启动/空闲也可能补零，不能单凭计数判断故障。异常后导出诊断。±100/±50/0ppm各8小时为控制器模型检查；真实发送循环与重采样另做短程回环验证。

## 曲目、封面与进度同步

体验入口新增 `--media-info`：读取Windows已公开的系统媒体会话，将曲名、作者、专辑、封面和进度通过已有加密控制连接发送给本次音箱；仅内存处理，不把媒体内容写入诊断或磁盘。普通EXE不开启此项。接收端未声明对应能力时不发送；同一文本/封面去重，拒绝可选格式后本次不重复尝试。

只选择唯一处于播放状态且明确标记为音乐的系统媒体会话；视频、未知类型不发送曲目封面，已有信息请求清空；暂停、退出、多个媒体会话同时播放或读取失败时请求清空旧信息。没有集成Windows媒体控制的应用无法提供信息；系统混音也可能包含未注册的其他声音，因此这里的曲目不代表对全部音频来源的识别。封面缩放至最长512像素，单张最多1MiB；进度按带时间戳的媒体快照推进。

建议验证单播放器切歌、封面变更、拖动进度、暂停和退出，再验证两个播放器同时播放时的清空。接收端接受请求不等于控制中心一定展示，也不代表Sound Glow已验证。断联/被接管后不补发清空，不向新所有者写入；正常退出由既有TEARDOWN结束本次会话。媒体信息模块不读取家庭设置、不更改播放器播放状态。

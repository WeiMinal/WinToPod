# V1.2 实现与验证矩阵

2026-11-15。状态对应当前development，不构成正式支持承诺。原生组合是家庭App已建立的立体声对；所有模拟结果都不代表实际出声。设备型号、固件和能力分别判断，未知型号不会被营销名称白名单拒绝。

## 当前优先级（2026-11-15，用户确认）

本节为当前执行顺序，覆盖历史段落中的旧优先级与“下一次继续位置”；不改变各项实际实现/验证状态。

| 优先级 | 方向 | 下一步及验收边界 |
| --- | --- | --- |
| P0 主线 | BASE-07：Windows全局补偿与外置音箱体验 | 提升为当前主线；先建立跨应用覆盖与延迟测量方案，分别验证全局画面补偿和音频低延迟路径。不依赖逐站浏览器助手作为最终方案。验证普通桌面应用、浏览器、本地播放器，以及受保护内容/独占全屏的边界；游戏、通话等实时场景须单列实际音频延迟，不能以延后画面判通过。虚拟音频设备是候选方案，尚未定型或实现。 |
| P0 主线 | HP-03/04/05：27.2相关媒体体验 | 提高曲名、作者、专辑、封面、进度及音乐/视频切换的实际验证优先级。软件媒体链路已有，需确认实际播放器取值、HomePod接收显示与清空、单只/原生对一致性；灯效只在设备支持时实测。通用元数据传输不称为27.2独有能力，灯效等官方能力与设备条件须核实。 |
| P0 基础收尾 | 组合发现与连接可靠性 | 跟进c7a8067 Windows构建和体验包，验证启动/连接前自动补查、取消和正常组无额外扫描；实际出声仍待用户设备验证。 |
| P1 | 稳定性与新策略验收 | 持续覆盖长播、暂停/静音恢复、抢占退让、休眠和网络异常；关键回归阻断发布。 |
| P2 辅助 | BASE-02/03：浏览器及特定播放器补偿 | 保留现有能力作过渡、对照和兼容回退；助手安装、商店分发及逐站完善不再优先于全局主线。 |
| 后续 | 新硬件、Mac/Apple TV接收、独立多目标、四音箱环绕 | 保留原目标及验证边界，不自动扩充本轮交付范围。 |

执行约定：优先完成可独立推进的软件工作，集中交付对应提交的体验包和必要真机步骤；本地无法替代的声学延迟、显示/灯效结果明确待实测。全局路线可行性和覆盖范围尚未确认，不承诺已实现所有应用无感同步。每批同步进度、矩阵、决策、包与源码对应关系。

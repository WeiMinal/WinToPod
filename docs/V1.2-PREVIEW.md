# V1.2 播放稳定性体验

这是开发体验包，未经本轮HomePod真机验收；程序内版本暂保留V1.1，不是正式V1.2。27.2灯效和新HomePod真机适配尚未完成。

先从托盘退出旧程序，完整解压到独立目录。双击 `Start-V1.2-Preview.cmd` 启用时钟对齐发送、采集率补偿和有限卡顿恢复；日志应出现“已启用V1.2时钟对齐与采集率补偿试验”。双击普通 `WinToPod.exe` 使用原策略作对照；切换前须退出托盘。登录启动仍使用原策略，体验开关不保存。

两种入口共享现有配对、音量和设置；原有自动连接偏好仍生效。采集断供后需要重新积累约100ms输入。PTP失效、失去控制权等保护保持原样。合成波形不等于听感验收。

建议低音量开始，依次验证：单只/立体声双只可听与左右声道；相同音源的低音量、人声、高频音质；暂停30秒再恢复重复5次；静音恢复；iPhone接管后的退让；连续播放1–2小时（有条件到8小时）；兼容播放器声音。记录爆音、变调、起音缺失或断联时刻。

每30秒及停止时的“采集率补偿”行包含补偿ppm、缓冲、丢弃、补零、重新预缓冲和限幅计数。启动/空闲也可能补零，不能单凭计数判断故障。异常后导出诊断。±100/±50/0ppm各8小时为控制器模型检查；真实发送循环与重采样另做短程回环验证。

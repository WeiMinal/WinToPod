# WinToPod V1.0 使用说明

退出旧程序并完整解压 `WinToPod-V1.0-win-x64.zip`，运行 `WinToPod.exe`。无需另装 .NET；已有本地配对、音量和偏好保留。

连接前保持 Windows 与音箱在同一局域网。单只音箱可以直接连接；原生立体声对先通过 iPhone 家庭 App 建立。软件只在接收端要求时提示输入 AirPlay 密码，已有有效验证可继续使用。

首页点击设备旁的“连接”或双击设备行。左侧音量图标用于静音/恢复，右侧用于选择来源；默认“全部应用声音（推荐）”。来源变更在下次连接生效。初次从低音量开始，按实际听感调整；有需要可在“设置 → 诊断 → 声音检查”测试当前连接。

“常规”顶部选择使用权模式。保守模式中断后等待手动重连，激进模式在本机使用条件下有限重试。登录启动、记忆目标自动连接和关闭后托盘运行分别设置。手动断开会暂停本次自动动作；远程或锁屏时先待机。

关于页显示 V1.0、功能与许可。透明图案随运行窗口/托盘所在主题切换；首页没有额外重复 Logo。桌面或固定快捷方式可能仍显示系统缓存的静态图标。

音画补偿为实验功能，需要首次在 Edge/Chrome 扩展管理中手动加载“浏览器音画补偿”文件夹。B 站默认启用，连接后自动跟随。系统级全局补偿、多只独立音箱同步、Apple TV/Mac 完整兼容尚未完成。

异常时从“设置 → 诊断”导出并先检查内容。不要分享 `%LOCALAPPDATA%\WinToPod` 中的配置或凭据；必要时只提供版本、系统版本、复现步骤与处理过的诊断。详细限制以 README 为准。

# V1.2 实现与验证矩阵

2026-11-15。状态对应当前development，不构成正式支持承诺。原生组合是家庭App已建立的立体声对；所有模拟结果都不代表实际出声。设备型号、固件和能力分别判断，未知型号不会被营销名称白名单拒绝。

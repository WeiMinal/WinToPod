# WinToPod V1.1 使用说明

退出托盘中的旧程序，完整解压 `WinToPod-V1.1-win-x64.zip`，双击根目录 `WinToPod.exe`。保留旁边的 `app` 文件夹；无需另装 .NET 或 Windows App SDK。主要面向 Windows 11 x64。

电脑与 HomePod 连接同一局域网，双击发现的音箱连接。立体声对请先在 Apple 家庭 App 中组合。仅在接收端要求时输入家庭 AirPlay 密码，不需要 Apple ID 密码。

首页调节音量、切换静音与 Windows 默认输出。输出切换会修改系统的常规/多媒体默认设备，不修改通信默认设备；应用单独指定的输出由 Windows 保留。程序使用应用混音采集，避免系统主音量与音箱音量重复衰减；不支持所需采集接口时会明确报错。

音量从低档开始调整。V1.1 的中低档控制映射较柔和，0 为静音。滑块数值与响度感受不保证严格线性，也不保证与 iPhone 每个位置完全相同；音源、摆放和音箱设置都会影响听感。

设置首页包含登录启动、自动连接、关闭后留在托盘。外观可选跟随系统、浅色或深色；任务栏及托盘图标跟随 Windows 系统模式。连接与播放、音画补偿、帮助与诊断均按需进入，高级选项默认折叠。设置即时保存。

保守模式中断后等待手动连接；激进模式仅在近期有本机操作且允许重试时有限重连。原生立体声对支持作为一个目标；多只独立音箱同步及系统级全局音画补偿尚未实现。HomePod 缓冲有延迟，不适合作为游戏或通话的低延迟输出。

浏览器音画补偿助手位于 `app/浏览器音画补偿`，首次需在浏览器手动安装授权，详见其中说明。本地视频补偿需要自行安装兼容的 VLC/mpv。

配对、音量和设置保存在 `%LOCALAPPDATA%\WinToPod`，升级完整替换程序文件夹即可保留。移动程序后，在设置中重新关闭、开启登录启动以更新路径。遇到问题可在“帮助与诊断”导出诊断，分享前检查内容；不应公开配对文件、播放凭据或完整配置。

程序未做代码签名。源代码、许可、已知限制与检查范围见 GitHub 仓库；本包许可证位于 `app/LICENSE`、`app/licenses`，检查报告位于 `app/VALIDATION.json`。

# 设置排布规范

设置遵循渐进式披露，后续新增选项保持相同原则。

1. 首页保留设备连接、音量、静音与 Windows 输出设备等日常操作。
2. 设置首页直接显示随 Windows 启动、自动连接上次音箱、关闭后留在托盘三个常用开关；其他能力只提供简短入口与当前状态。
3. 连接与播放中选择音箱使用权策略。仅在选择激进模式时显示对应重试说明；验证与兼容操作默认折叠，单只兼容仅对所选组合展示。
4. 音画补偿先选择浏览器或本地视频，随后展示对应操作。手动微调默认折叠，不把高级参数放在功能首屏。不添加没有后端支持的假开关。
5. 帮助与诊断先提供声音检查，再提供连接详情与日志导出。首页出错时提供直达入口，避免排障藏得过深。
6. 关于仅先显示品牌、版本与一句简介，许可与项目说明按需展开。
7. 返回按钮与 Escape 按层级返回；保留自然滚动以适配小窗口和较大文字，禁止为了首屏塞满而固定内容高度。
8. 新增设置先判断使用频率、前置条件和影响范围，决定放置层级；不要仅按内部技术模块增加一排并列标签。

Windows设置切换、自动连接、托盘、补偿与诊断仍复用现有控制器。所有设置保持即时保存。

外观入口：设置首页显示“外观”及当前选择；进入后选择跟随系统/浅色/深色，即时生效并保存。主窗口、标题栏、品牌图标和中断提示统一跟随，不提供没有明确需求的自定义颜色系统。

图标主题规则：应用内部及标题栏图标按WTP外观适配；任务栏和托盘图标按Windows系统模式适配。自选深色/浅色不得降低系统任务栏中的辨识度。窗口图标使用SetTitleBarIcon与SetTaskbarIcon分别设置，不再用SetIcon覆盖两处。

设置页滚动条：闲置约1.2秒后以180ms淡出；滚动、键盘翻页、右侧24DIP区域接近时显示，悬停/拖动时保持可用。使用原生ScrollViewer及其模板滚动条，只调视觉与命中，不通过Hidden/Auto反复切换改变排版；页面卸载时停止计时和动画。此交互统一应用到各设置子页，不新增外观开关。

# 音量与采集

WinUI 使用 `desktop-calibrated-v1` 映射。设面板比例 x = 百分比 / 100，非零音量对应分贝为 `-30 + 30 × (4x³ + 3x² + 8x) / 15`；0 为静音，100 为 0 dB。该曲线连续、严格递增，低于原生线性分贝映射的中间档位：25% 对应 -25.5 dB，50% 对应 -19.5 dB。它来自试听调校，不是 Apple 官方曲线或声学响度标定。

系统主音量与 HomePod 音量联动；采集必须发生在系统主音量之前，PCM 增益保持 1，不再叠加系统主音量衰减。不支持所需应用混音采集接口时明确报错，不静默回退到有重复衰减的采集路径。

音量 SET 发送一次，合法但不匹配的 GET 最多四次，间隔 100/200/300 ms，确认容差 0.25 dB。仍未收敛时保留原确认值并提示，不因单次旧回读终止健康会话；首次未确认不开始发送声音。无效回读、拒绝、连接中断及会话失去使用权继续按真实故障处理。新旧操作使用修订号区分，避免旧请求覆盖新输入。

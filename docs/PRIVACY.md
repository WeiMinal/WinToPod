# 隐私与本地数据

WinToPod 直接与局域网接收端通信，没有遥测、账号登录、云同步或自动诊断上传。软件不需要 Apple ID。系统声音采集在连接期间运行，不采集麦克风，不将音频录制到文件。

## 保存什么

数据仅保存在 `%LOCALAPPDATA%\WinToPod`：

| 文件 | 用途 |
| --- | --- |
| `desktop-settings.json` | 成功目标、成员身份、音量、等待截止时间、使用权与启动偏好、所选来源/播放器路径。 |
| `paired-receivers.dat` | 发送端配对身份和接收端公钥，使用当前 Windows 账户 DPAPI 加密。 |
| `playback-credentials.dat` | 针对接收端及挑战范围派生的播放验证材料，使用相同账户保护。 |

家庭 AirPlay 密码不明文落盘；密码输入与验证仍需要暂存在进程内存。派生播放材料与配对密钥具有敏感性，加密文件也不应公开分享。配置中的接收端身份和本机文件路径不属于可公开样例。

“登录 Windows 后启动”只维护当前用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\WinToPod` 项；关闭开关可撤销。程序不安装驱动或系统服务。

## 自动连接与本机输入

输入监测仅用于判断近期是否有本机按键按下/鼠标按钮操作，以及远程或锁屏状态。不读取按键文本、扫描码、鼠标坐标、剪贴板或输入内容，不保存输入历史。第三方远控和特殊虚拟输入无法保证完全区分；用户可以关闭自动连接。

## 诊断

常规记录保留在内存；只有手动导出才创建 ZIP。导出保留版本、接收端型号/系统特征、协议状态、包数、采集计数与音量等排障字段。不含原始音频、密码、配对密钥或整份配置。

导出过滤已知设备名称、身份、本机用户名/路径、IP 和 MAC；接收端代号使用每次导出独立的随机密钥生成，避免不同诊断直接关联。过滤属于尽力处理，任意异常文本仍应在分享前检查，不能视为彻底匿名化承诺。

## 可选播放器与浏览器助手

只控制用户明确由 WinToPod 打开的 VLC/mpv 实例。浏览器助手与 `127.0.0.1:38765` 交换连接状态、延迟和限定格式的呈现计数，不上传视频画面、网页地址、播放历史或账号信息。B 站匹配权限默认声明；其他站点由用户单独授权，授权可在浏览器撤销。助手的视频缓冲仅在内存，断开或退出时释放。

## 停用和删除

先关闭登录启动并从托盘退出，便可删除解压后的程序文件夹。需要彻底清除时再删除上述本地数据目录；这会丢失配对、播放验证及音量设置，下次使用可能需要重新输入密码。不要在仍播放或未备份所需配置时删除。

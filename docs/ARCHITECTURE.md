# 实现结构

| 组件 | 职责 |
| --- | --- |
| WinToPod.Desktop | WinForms 原生窗口/属性页，WPF Fluent 首页，WASAPI/应用混音采集，托盘、主题、输入门控和本地凭据适配。 |
| WinToPod.Core | 现行自动连接策略、PCM 缓冲/合并、连接内测试音、采集延迟估算、视频状态桥及诊断过滤。 |
| WinToPod.AirPlay | DNS-SD/mDNS 解析、原生对识别、SRP/完整配对与验证、加密 RTSP、Digest、事件通道、ALAC/RTP 以及 NTP/PTP 时钟。 |
| WinToPod.Discovery | 独立的命令行扫描入口，不发起配对、播放或音量控制。 |
| WinToPod.Checks | 无真实接收端的基础检查及独立模拟的 .NET 驱动。 |

原生立体声对保持家庭 App 已有分工：发送完整立体声给每个成员，共享采集帧、RTP 时间轴和播放锚点，各成员独立控制密钥、传输与重传。不会按设备名称猜测左右，也不把两只独立音箱伪装成原生对。组内失败停止整组；用户确认单只兼容后合并左右内容。

默认 Windows 应用混音采集排除本进程树；本软件启动的兼容播放器另行包含，避免重复采集。样本不做额外自动增益。静音使用 PCM 静音门并继续原会话的静音音频，接收端正常化静音回读不会单独造成整组断开。

界面与协议状态分离。连接生命周期和音量操作由桌面宿主管理，保守/激进自动动作经过近期本机输入和会话条件约束；广播和故障类型均不被当作其他设备占用的可靠证明。

实现代码为本项目编写；通用密码原语由 BouncyCastle/.NET 提供，采集封装依赖 NAudio，未嵌入另一 AirPlay 发送端。协议公开资料是行为研究参考，不构成 Apple 官方兼容认证。实际边界见 README。

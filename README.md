# WinToPod

**把 Windows 的声音，送到 HomePod。**

WinToPod 是独立实现的 AirPlay 音频发送软件，面向 Windows 11，支持单只 HomePod / HomePod mini，以及在 Apple 家庭 App 中建立的原生立体声对。首次连接完成后，可以在本机使用时自动连接上次音箱，在其他设备接管时按你的偏好退让或重连。

当前版本：**V1.0**。界面、协议发送与设备管理均为本项目实现，没有把其他 AirPlay 发送项目作为运行引擎。开发中曾在真实 HomePod mini 立体声对上确认双只发声；兼容性仍可能随接收端系统升级变化。本项目与 Apple、Microsoft 无关联。

## 能做什么

- 发现同一网络内的 AirPlay 接收端；点击设备旁的连接，或双击设备行连接。
- 向单只 HomePod / HomePod mini、原生立体声对发送 Windows 应用声音；组合失败时，经你确认可先用一只。
- 联动 Windows 和音箱音量，点击图标静音；让出后停止音量控制，重连恢复各目标上次确认音量。
- 登录启动、记住成功目标；检测到近期本机操作后尝试自动连接，远程会话或锁屏时先待机。
- 默认保守模式：中断后保留重新连接入口并发出 Windows 通知。可选激进模式：在近期本机操作条件下有限重试。
- 原生紧凑设置页、系统明暗主题、透明睡猫图标和托盘菜单。诊断仅在手动导出时生成。

## 开始使用

1. 下载 Releases 中的 `WinToPod-V1.0-win-x64.zip`，完整解压到固定位置，运行 `WinToPod.exe`，无需另装 .NET。
2. 电脑与音箱连接同一局域网。原生立体声对请先在 iPhone 的家庭 App 中组合；WinToPod 不拆改组合或左右声道分工。
3. 连接搜索到的 HomePod。仅在接收端要求时输入家庭 AirPlay 密码，不需要 Apple ID 密码。
4. 播放音乐，从低音量开始调整。首页左侧图标切换静音，右侧图标选择电脑声音来源。
5. 如需日常后台使用，在“设置 → 常规”启用登录启动、自动连接或关闭后留在托盘。

建议使用 Windows 11 x64。局域网需允许设备发现与音频通信；客户端隔离、访客网络或防火墙规则可能阻止连接。首次出现系统网络提示时，仅为你信任的家庭网络放行。程序未做代码签名，Windows 可能显示未知发布者，请核对下载来源与 SHA256。

升级时先退出托盘中的旧程序，再替换完整文件夹。配置位于 `%LOCALAPPDATA%\WinToPod`，不会随解压目录覆盖；已有配对和音量记录保留。开启登录启动后，请保留程序所在位置。

## 使用权与自动连接

| 设置 | 行为 |
| --- | --- |
| 保守模式（默认） | 发现中断后停止发送和音量控制，保留应用内提示与系统通知，等你手动重新连接。 |
| 激进模式 | 仅在会话允许且近期有本机输入时尝试重连，按 10 / 30 / 90 秒退避，最多 3 次；优先遵守音箱要求的等待。 |
| 启动自动连接 | 需要已有成功连接目标和近期本机输入；RDP、锁屏或无法确认的输入先待机。 |
| 手动断开 | 暂停本次自动连接，不立即抢回音箱。 |

设备广播不能可靠证明 HomePod 正被谁使用，也不能保证识别所有第三方远控。若经常远程开机且家中有人使用音箱，可以关闭自动连接，保持默认保守模式。

## 当前限制

- 多只**独立**音箱同时播放和混合同步尚未完成；原生立体声对作为一个目标受支持。
- 系统级全局音画补偿尚未实现。HomePod 音频缓冲会带来延迟，不适合作为游戏、乐器或通话的低延迟输出。
- 随包浏览器助手提供实验性网页画面补偿，首次需要手动安装授权；B 站默认启用。弹幕/页面字幕不会一起延后，DRM、画中画和部分全屏方式暂不支持。详见 [助手说明](browser/WinToPod.VideoSync/使用说明.md)。
- Apple TV 和 Mac 可能被发现，但目前不承诺可听播放；已知部分 Apple TV 可连接无声、部分 Mac 拒绝鉴权。
- 默认采用 Windows 原生应用混音采集；无法激活时回退端点采集，结果记录在诊断中。低档音量听感、驱动差异和长期稳定性仍需真机反馈。
- 窗口及托盘随各自 Windows 主题换用黑白透明图标。EXE 文件和已固定快捷方式受系统静态图标与缓存机制限制，不能保证即时换色。

## 源码与构建

构建需要 .NET 10 SDK、Python 3.11+ 和 PowerShell 7。仓库结构如下：

| 目录 | 内容 |
| --- | --- |
| `src` | Windows 界面、音频采集、设备发现、配对、加密控制与音频发送。 |
| `browser` | 可选的浏览器音画补偿助手。 |
| `tests` | 独立接收端模拟、采集边界、视频生命周期及浏览器检查。 |
| `tools` | 构建、打包、品牌资源生成和发布内容检查。 |
| `docs` | 使用、构建、架构、协议参考与验证范围。 |
| `licenses` | 原始第三方许可证。 |

在 Windows PowerShell 中构建便携包：

```powershell
pwsh -File tools/Build.ps1
python tools/Package.py
```

产物位于 `artifacts/release`。源码检查、协议模拟及跨平台构建见 [开发说明](docs/BUILD.md)，已执行范围见 [验证说明](docs/TESTING.md)。工作流只检查和构建，不自动创建 GitHub Release。

## 隐私、反馈与许可

不内置遥测，不自动上传日志，不采集麦克风或保存录音。必要的配对身份与派生播放凭据通过 Windows 当前账户 DPAPI 加密保存，不将家庭密码明文写入文件。详情及卸载方式见 [隐私说明](docs/PRIVACY.md)。

问题反馈请提供版本、Windows/音箱系统版本和复现步骤。需要诊断时，从“设置 → 诊断”导出并先检查内容；不要上传配对文件、播放凭据或完整配置。公开源码不包含真实设备诊断、上传原图或本机配置。协议测试中的口令、密钥、地址和名称均为合成夹具。
